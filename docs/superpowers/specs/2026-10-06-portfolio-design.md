# Portfolio design
Approved design: a bilingual English/Persian Next.js portfolio on GitHub Pages. The user delegates routine decisions and asks to skip further approval gates.
An editorial warm paper surface, ink typography, vermilion accent, generous whitespace, and large project artwork composed from abstract product motifs. Illustrative artwork must not pretend to be product screenshots.
Routes /en and /fa are statically generated, with / redirecting to /en. Each page has a header, introduction with a visible featured project motif, selected work, experience, skill groups, resume downloads, contact, and footer. Seven project records share typed localized content. Standard links provide language switching, section navigation, downloadable PDFs, email, LinkedIn and the supplied portfolio URL. Project details use native accessible details/summary. No form or database required.
Preserve exact durations: MCI Shop 5 months, Ava Hamrah 3, Inbox 3, Phantom 2, Sport Zarebin 2, internship 4. Ava and Inbox remain planned launches. Bubble and Shahdaei have no invented durations. Do not assign invented user counts.
Use locally hosted fonts, semantic landmarks, visible focus states, reduced-motion support, RTL layouts, correct per-route lang/dir, metadata and social image. Test both languages, small screens, links and downloads, build and type checking before deployment.
